# Vansh's Personal Portfolio 🚀

A modern, responsive, and animated personal portfolio website built to showcase my projects, skills, education, and professional experience. Designed with a focus on immersive aesthetics and interactive user experiences.

## 🔗 Live Demo
**[View Portfolio Live](https://vansh-portfolio-mauve.vercel.app/)**

## ✨ Core Features & Sections

The portfolio is structured into various comprehensive sections, providing a complete overview of my professional journey:

- **About:** A brief introduction to who I am and my core priorities.
- **Skills:** A cleanly categorized display of my technical toolkit, from programming languages to frameworks and tools.
- **Experience:** A detailed vertical timeline of my professional roles, internships, and impact.
- **Work (Projects):** Interactive, 3D tilt-enabled cards showcasing my best projects alongside live links and source code.
- **Education:** A visual timeline covering my academic background.
- **Volunteering & Extracurriculars:** Insights into my personal initiatives, community involvement, and interests outside of regular coding.
- **Contact:** A fully functional contact form securely powered by EmailJS, complete with elegant toast notifications.

## 🎨 UI/UX Highlights

- **Dynamic Scroll Progress Bar:** A fixed top-level gradient bar tracking reading progress natively mapped to scroll depth via Framer Motion.
- **Immersive Backgrounds:** Ambient pulsing glowing orbs mixed with a subtle dot-grid mask for a premium, glassmorphic atmospheric feel.
- **Micro-Animations & Interactions:** Smooth entrance animations for cards and text formatting, hover zoom effects, and engaging 3D parallax tilt bounds.
- **Responsive Layout:** A clean translation of desktop layout into an optimal mobile-friendly experience.

## 🛠️ Tech Stack under the Hood

This project leverages modern web development tools to maintain high performance and rich interactivity:

- **Frontend Framework:** React.js (v18)
- **Build Tool:** Vite for blazing-fast page loads, hot-module replacement, and optimized compilation.
- **Styling Methodology:** Tailwind CSS for rapid, scalable, and responsive UI construction.
- **Animation Engine:** Framer Motion for complex scroll-linked and viewport-driven physics animations.

### Noteworthy Libraries Utilized:
- `@emailjs/browser`: Handles seamless direct contact messaging.
- `react-parallax-tilt`: Drives the engaging, interactive 3D tilt effects primarily on project and experience cards.
- `react-typing-effect`: Provides the dynamic hero text typing interactions.
- `react-toastify`: Adds elegant, non-blocking pop-up notifications to confirm form submissions or interactions.
- `react-icons`: Used extensively for a rich suite of scalable SVG outlines and fill icons throughout the interface.
